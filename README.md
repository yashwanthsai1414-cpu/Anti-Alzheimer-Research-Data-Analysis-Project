# Anti-Alzheimer-Research-Data-Analysis-Project
# 📊 Treatment Effectiveness Analysis

## Overview

This project focuses on analyzing experimental data using Advanced Excel to evaluate the effectiveness of different treatments. It combines statistical analysis with interactive dashboards to generate meaningful insights.

## Key Features

* Performed data analysis using Advanced Excel tools
* Applied statistical techniques: minimum, maximum, average, and variance
* Built interactive dashboards for before vs after comparisons
* Visualized trends to track treatment performance over time
* Generated insights to identify best-performing treatments

## Insights

The analysis helps in understanding treatment outcomes, highlighting performance differences, and supporting data-driven decision-making.

## Tools Used

* Microsoft Excel (Advanced)
* Data Visualization Techniques
* Statistical Analysis Methods

## Outcome

Identified the most effective treatments through clear data comparisons, trend analysis, and statistical evaluation.
